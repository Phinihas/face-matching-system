\# Face Matching YuNet



Face matching system using OpenCV YuNet for face detection and AdaFace for face embeddings.



\## Project Structure



\- `backend/` - Face matching backend

\- `frontend/` - Frontend application

\- `analysis/` - Analysis and experiments

\- `docker\_services/` - Docker-related services

\- `datasets/` - Dataset-related files

\- `evaluation\_results/` - Evaluation results



\## Technologies



\- Python

\- FastAPI

\- OpenCV YuNet

\- AdaFace

\- Qdrant

\- Docker
